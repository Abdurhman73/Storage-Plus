# Storage-Plus
نظام إدارة المبيعات والمخزون هو تطبيق تجاري متكامل يهدف إلى تسهيل إدارة المتاجر وتنظيم عمليات البيع والشراء ومتابعة العملاء والحسابات المالية من مكان واحد.  يوفر التطبيق إدارة المنتجات والمخزون، وإضافة العملاء، وإنشاء فواتير البيع وطباعتها، وتسجيل المدفوعات، ومتابعة ديون العملاء والمبالغ المتبقية، بالإضافة إلى التقارير والإحصائيات في متابعة المتاجر
